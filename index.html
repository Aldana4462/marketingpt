Barra Retro Cafetera

Perilla de leche 0%

Gira para dosificar la espuma perfecta.

Guía rápida

  • Arrastra la barra “Nivel de café” para dosificar el espresso base.
  • Gira la perilla de leche para añadir la crema en la medida exacta.
  • Consulta el indicador junto a la perilla: muestra el porcentaje real de leche en la taza.
  • El botón “Llenar Gradualmente” prepara una taza completa con leche incorporada.
  • Si prefieres ver todo el flujo automáticamente, pulsa “Previsualizar”.

Ajusta el nivel de café y gira la perilla para tu mezcla ideal.
