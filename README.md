# marketingpt

## Previsualización local

1. Clona este repositorio y entra en la carpeta del proyecto.
2. Inicia un pequeño servidor estático, por ejemplo:
   ```bash
   python -m http.server 8000
   ```
3. Abre tu navegador en `http://localhost:8000/index.html` para interactuar con la cafetera retro.

El botón "Previsualizar" llena la taza automáticamente y muestra la animación de leche para que puedas ver el resultado sin mover los controles manualmente.
